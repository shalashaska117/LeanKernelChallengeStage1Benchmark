# Third-party sources

The benchmark wrapper is independent of the challenge organizers. It downloads the [Lean Kernel Challenge evaluator](https://github.com/SAIRcompetition/lean-kernel-challenge), released under Apache-2.0, at the revision in `upstream.lock.json`. Downloaded code and dependencies retain their own license files in `.cache/`.

Rules, problem definitions, and test-group metadata are summarized from that public revision. Each problem guide links to its source. The organizers' current rules take precedence for competition entries.
